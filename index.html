关于这个合集

技术形态

  • 纯静态 HTML / CSS / 原生 JS，无框架、无构建
  • 零外部依赖：Chart.js 与 Tailwind 已本地化，字体走系统栈
  • 完全离线可用，断网、内网、本地双击都能跑
  • 6 个测试全部在浏览器内算分，没有后端

隐私

  • 不收集、不上传任何作答数据
  • 无账号、无广告、无第三方统计
  • 收藏 / 历史 / 偏好只存在你自己的 localStorage

计分公平性

  • 每个测试都跑过 20 万次随机作答蒙特卡洛自检
  • 随机作答下各结果类型出现概率应当一致，偏离即说明结果被答案键的算术左右
  • 已修掉：数组顺序决定并列结果、分值池不均、题内分值不平衡等问题
  • 自检脚本见仓库 tools/audit.js，可随时重跑
心理测试合集 — 个人练习作品，非商业产品，结果仅供娱乐与自我参考，不构成任何心理诊断。
六个测试各自使用独立的视觉风格（国风 / 暗色西玄 / 粉色 / 简约），枢纽页统一为蓝白瑞士极简。
